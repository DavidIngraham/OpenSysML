- **A redefining feature answers to the redefined feature's short name.** A feature declaring neither a name nor a short name takes both from the feature it redefines (KerML 8.3.3.3 `Feature::effectiveShortName`), and name resolution now binds that short name as it already bound the name: with `part def ADS { part <tms> t : TMS; }` and `part gear : ADS { part :>> t { } }`, `gear.tms`, `gear::tms` and `sua.tms` for any `sua` that specializes, subsets or redefines `gear` bind to `gear`'s redefining feature rather than failing with `unresolved member: tms` or falling back to the hidden `ADS::t`. A redefining feature with a short name of its own (`part <t3> :>> t;`) keeps only that one, so the old short name no longer resolves through it, as in the pilot implementation.
